# 火山引擎 CEN 手动私网接入

本流程用于火山引擎同地域、跨账号 VPC 接入。客户完成授权和客户侧网络检查，Modalink 完成服务侧接入并提供服务入口。本文包含客户侧操作、信息交接和验收步骤。

步骤依据双方确认的《火山引擎 CEN 跨账号私网接入指南》整理；原指南可作补充参考。

## 1. 接入前核对和交换信息

| 提供方 | 信息 |
| --- | --- |
| 客户 | 火山引擎主账号 ID、地域、VPC ID、实际访问服务的来源子网 CIDR |
| Modalink | 主账号 ID、指定 CEN ID、相同地域、服务子网 CIDR、私网服务地址、协议和端口 |

使用双方主账号 ID，只交换接入所需信息；账号密码和 Access Key/Secret Key 保留在各自环境中。服务入口使用本次交付的实际地址。

接入前确认：

- 双方同地域，客户 VPC 未加载其他 CEN，操作账号具有相应权限。
- 实际互通子网 CIDR 不重叠，整体 VPC CIDR 也宜避免重叠；容器网络也需检查。CIDR 冲突不能靠放开安全组解决。
- 有现成的业务/训练实例用于验证，明确其实际来源子网。
- 本次 CEN 只承载约定的 Modalink 服务 VPC 和客户 VPC。

存在跨地域、共享 CEN、已有 CEN 接入或 CIDR 冲突时，先与网络管理员及 Modalink 确认方案，不直接卸载既有网络或扩大路由范围。

## 2. 授权指定 CEN

在客户账号下操作：

1. 打开火山引擎 VPC 控制台，选择目标 VPC 所在项目和地域。
2. 进入该 VPC 详情，打开“云企业网跨账号授权”页签。
3. 单击“云企业网跨账号授权”，填写 Modalink 提供的“对方账号 ID”和“对方云企业网实例 ID”。
4. 核对目标后确认，并在授权列表确认对应账号 ID 和 CEN ID 已出现。
5. 通知 Modalink，等待对方确认 VPC 已接入、服务侧网络已就绪，再进行客户侧验收。

授权允许指定 CEN 加载该 VPC，不授予客户计算资源或账号管理权限。授权记录存在不等于已加载 VPC，也不等于服务可访问。

## 3. 检查路由和访问控制

客户不拥有 Modalink 的 CEN，因此在自己的 CEN 列表中找不到它不能判定失败。在客户账号和训练环境检查：

| 检查项 | 期望结果 |
| --- | --- |
| 授权 | 指定 VPC 中存在 Modalink 账号及指定 CEN 的授权记录 |
| 路由 | 实际业务子网关联的路由表存在到 Modalink 服务子网的正常系统路由，下一跳类型为“云企业网” |
| 访问控制 | 实例安全组允许约定端口的访问，网络 ACL、主机防火墙或代理允许请求和返回流量 |

使用自定义路由表时检查实际关联表，不只检查默认表。缺少路由、路由冲突或出现未约定网段时，保留结果并联系 Modalink，不添加全网段、全端口放行规则。

训练在容器中运行时，最终请求也从该容器发出；宿主机可达不代表容器可达。请 Modalink 确认服务侧允许约定来源和端口，不能仅检查客户侧规则。

## 4. 从实际训练环境验收

使用现有业务/训练实例，按交付的真实地址和端口验证。以下命令选用目标环境支持的一种，变量均取实际交付值：

~~~bash
nc -vz -w 5 "$SERVICE_HOST" "$SERVICE_PORT"
~~~

~~~powershell
Test-NetConnection -ComputerName $ServiceHost -Port $ServicePort
~~~

端口探测后继续核对实际应用响应。网络应覆盖 scheduler、节点 control 以及数据通道；不能只测试一个入口就认为全部可用。数据地址由 client 自动获取，所需子网、端口和网关以交付资料为准。

随后按 [deployment.md](deployment.md) 完成安装、私有凭据配置、Token 保存和训练登记。公开仓库与包不含证书、私钥或 Token；在 TUI/SDK 使用前，用 `remote-loader config edit` 配置实际 Scheduler 和全部三项绝对 TLS 路径，自动云发现不能提供凭据。从每台训练主机或容器各运行一次汇总当前训练全部已分配节点的连接诊断，不按 GPU 或 `LOCAL_RANK` 重复。有限试读仍使用实际 `RANK/LOCAL_RANK/WORLD_SIZE`，且不要与正在训练的 loader 争用同一 GPU 的数据资源。数据输出及图像要求见 [用户指南](../../../user-guide.md)。

验收应包含：客户授权记录、Modalink 接入就绪确认、客户侧路由及访问控制检查、实际应用请求和数据读取。`ping` 失败不能单独证明 CEN 不通；仅控制台、TCP 或连接诊断成功也不能证明已经读取数据。没有可发起请求的训练环境时，端到端验收仍未完成。

## 5. 失败定位与解除接入

| 现象 | 下一步 |
| --- | --- |
| 已授权但没有服务路由 | 核对 VPC 授权、实际关联路由表、账号和地域；联系 Modalink 确认接入状态 |
| 路由正常但端口超时 | 检查安全组、网络 ACL 和主机防火墙；提供来源 IP、目标地址/端口及错误，请 Modalink 检查服务侧 |
| TCP 可达但应用失败 | 检查私网 DNS、TLS 主机名、Token、应用权限和实际协议 |
| 连接诊断正常但读不到数据 | 检查实际数据通道是否可达，保留读取错误并联系 Modalink 确认服务状态 |

解除接入前先停止读取并完成 [训练资源释放](deployment.md)。随后联系 Modalink 卸载客户 VPC；收到完成确认、核实客户侧服务路由消失后，再撤销指定 CEN 授权并清理本次客户侧访问规则。保留其他业务的授权、路由和安全规则。当前 client CLI 不提供火山 CEN 创建或删除命令。

## 6. 不明确事项的处理

地址/端口、账号/VPC/CEN、共享网络范围或操作权限不明确时，先向负责的网络管理员或 Modalink 确认，再进行依赖该信息的网络变更。保留双方确认的信息、已完成阶段、剩余检查和负责方，不记录密钥。
